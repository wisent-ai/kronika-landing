Docs/CLI/check
Kronika CLI command

kronika check

Audit one exact Git change against the current documentation through Brama. The command is a fail-closed documentation consistency gate.

Invocation

kronika check --base <ref> [options]

--base <ref> is required. BRAMA_URL (or MODEL_ROUTER_URL) and BRAMA_API_KEY (or MODEL_ROUTER_TOKEN) are also required. The repository must be a Git repository with both refs resolvable as commits.

Inputs and options

OptionDefaultEffect
--base <ref>requiredBase commit of the three-dot Git range.
--head <ref>HEADHead commit of the audited range.
--repo <path>current directoryRepository to audit.
--output <path>README.mdDocumentation target considered by source collection.
--source <path>automatic discoveryExplicit audit evidence; repeatable.
--instruction <text>standard completeness auditAdditional documentation goal sent with the exact change.
--model <selector>KRONIKA_MODEL or anyBrama model selector.
--max-input-bytes <n>200000Total source budget.
--max-file-bytes <n>64000Per-file source limit.
--max-diff-bytes <n>200000Maximum complete diff size; a larger diff is refused, never truncated.
--max-tokens <n>8000Completion token budget.
--timeout-ms <n>120000Brama request timeout.
--jsonoffEmits the machine-readable result.

Output and state

Kronika resolves both refs, reads the base...head diff with rename detection and 40 lines of context, collects current safe sources, and asks Brama for a strict verdict. Text output starts with Kronika documentation check: PASSED or BLOCKED, followed by the summary and findings. JSON output contains passed, summary, findings, model, resolved SHAs, changed paths, diff bytes, source count, and skipped sources.

The command writes no repository state. It exits 0 exactly when there are no blocker findings; warnings do not block. It exits 1 for a blocker or any operational/validation failure.

Exact refusals

  • check requires --base <ref>
  • Git commit cannot be resolved: <ref>
  • Git diff cannot be read for <base-sha>...<head-sha>
  • Git diff is <n> bytes, above --max-diff-bytes <limit>; narrow or split the change rather than auditing a truncated diff
  • BRAMA_URL or MODEL_ROUTER_URL is required and BRAMA_API_KEY or MODEL_ROUTER_TOKEN is required
  • Malformed model results are refused, beginning with Kronika returned invalid documentation-check JSON; a verdict inconsistent with blocker findings is Kronika documentation check contradicts its blocker findings.

Source containment, symlink, existence, UTF-8, and byte-budget rules are the same as kronika sources. Parser and runtime errors are written as kronika: <message> to stderr.
