Docs/CLI/write
Kronika CLI command

kronika write

Generate one complete Markdown document through Brama from the selected repository sources and an optional writing instruction.

Invocation

kronika write [options]

No command option is required. BRAMA_URL (or MODEL_ROUTER_URL) and BRAMA_API_KEY (or MODEL_ROUTER_TOKEN) are required. By default Kronika previews a generated README.md for the current directory.

Inputs and options

OptionDefaultEffect
--repo <path>current directoryRepository root.
--output <path>README.mdTarget document inside the repository.
--source <path>automatic discoveryExplicit source file or directory; repeatable.
--instruction <text>standard complete-document goalAdditional writing goal.
--model <selector>KRONIKA_MODEL or anyBrama model selector.
--max-input-bytes <n>200000Total source budget.
--max-file-bytes <n>64000Per-file source limit.
--max-tokens <n>8000Completion token budget.
--timeout-ms <n>120000Brama request timeout.
--applyoffAtomically replaces the target document.
--jsonoffEmits metadata and, for a preview, generated content as JSON.

Output and state

Without --apply, stdout is the normalized generated Markdown and no file changes. With --apply, Kronika writes a temporary file beside the target, preserves an existing target's mode (or uses 0644), and renames it into place atomically. Text confirmation is Wrote <path> from <n> source files via Brama.

--json emits outputPath, applied, model, sourceCount, and skipped; a preview also includes content. A surrounding Markdown fence is removed and accepted output ends with one newline. Success exits 0.

Exact refusals

  • BRAMA_URL or MODEL_ROUTER_URL is required
  • BRAMA_API_KEY or MODEL_ROUTER_TOKEN is required
  • Output is outside the repository: <output>
  • No safe UTF-8 source files were selected
  • Brama returned documentation that is too short
  • Brama returned invalid NUL content

Source containment, symlink, existence, UTF-8, and byte-budget rules are the same as kronika sources. Value-taking flags without a value, non-positive numeric values, unknown options, Brama failures, and file-system failures also exit 1 with kronika: <message> on stderr.
